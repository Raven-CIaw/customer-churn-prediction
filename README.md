
# Customer Churn Prediction

A machine learning project that predicts customer churn using a calibrated Decision Tree classifier.

## Features
- Customer information input through Streamlit
- Customer churn prediction
- Estimated churn probability
- Scikit-learn preprocessing and model inference

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit

## Run Locally

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## Model
The application uses a trained classifier and a fitted
StandardScaler saved as pickle files.

## Disclaimer
Predictions are estimates and should not be treated as
guaranteed outcomes.
